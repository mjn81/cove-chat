---
title: Быстрый старт
description: Запустите собственный сервер Cove и веб-клиент с помощью Docker примерно за пять минут.
---

:::caution[Бета]
Cove находится в стадии бета-тестирования. Возможны шероховатости: делайте резервные копии данных и мастер-пароля и сообщайте о проблемах на [GitHub](https://github.com/mjn81/cove-chat/issues).
:::

В результате на одной машине будут работать сервер и веб-клиент. Понадобится [Docker](https://docs.docker.com/get-docker/) с Compose.

## 1. Создайте папку и скачайте файлы

```bash
mkdir cove && cd cove
curl -O https://raw.githubusercontent.com/mjn81/cove-chat/main/examples/docker-compose/production/docker-compose.yml
curl -o config.toml https://raw.githubusercontent.com/mjn81/cove-chat/main/backend/config.toml.example
mkdir data
```

## 2. Укажите веб-клиенту адрес сервера

Откройте `docker-compose.yml` и задайте для сервиса `frontend` переменную `VITE_API_URL` — адрес, по которому люди будут обращаться к API, например `https://chat.example.com:4000`. Для пробного локального запуска подойдет значение по умолчанию `http://localhost:4000`.

Затем укажите в `config.toml` в параметре `frontend_origin` адрес веб-клиента (например, `http://localhost:3000`). Сервер принимает запросы из браузера только с этого источника (origin).

## 3. Запустите

```bash
docker compose up -d
```

| Порт | Назначение |
|---|---|
| `3000/tcp` | Веб-клиент |
| `4000/tcp` | API и WebSocket |
| `3478/udp` | Встроенный STUN/TURN для звонков |
| `50000-50100/udp` | Медиатрафик WebRTC |
| `9090/udp` | Зашифрованные медиаданные по UDP (только при `voice.mode = "raw_udp"`) |

## 4. Создайте аккаунт владельца

Откройте `http://localhost:3000` и зарегистрируйтесь. **Первый аккаунт на новом сервере становится владельцем.** У владельцев и администраторов в настройках появляется вкладка администрирования сервера (*Server admin*).

:::caution[Сохраните копию мастер-пароля]
При первом запуске сервер создает мастер-пароль и записывает его в `config.toml`. Этим паролем зашифрован ключ базы данных. Если потерять его, данные восстановить нельзя. Скопируйте его в надежное место прямо сейчас.
:::
