Cove находится в стадии бета-тестирования. Возможны шероховатости: делайте резервные копии данных и мастер-пароля и сообщайте о проблемах на [GitHub](https://github.com/mjn81/cove-chat/issues).
:::

Cove — это чат-платформа на вашем сервере для сообществ, которые хотят сами владеть своими данными. Вы запускаете один сервер, люди подключаются через веб-клиент, приложение для компьютера или Android, и все (сообщения, файлы, голос и видео) остается на оборудовании, которое контролируете вы.

## Что вы получаете

- Текстовые каналы, личные сообщения и друзей, а также роли и панель администратора
- Групповые аудио- и видеозвонки и демонстрацию экрана, встроенные в сервер
- Голосовые сообщения, обмен файлами и видеосообщения
- Чаты **Whisper** со сквозным шифрованием, которые нигде не сохраняются
- Интерфейс на английском, персидском, арабском и русском языках, включая письмо справа налево
- Один бинарный файл Go со встроенной базой данных, настраиваемый одним файлом `config.toml`

## Модель доверия в одном абзаце

В Cove используется **шифрование с доверенным сервером**. Сообщения шифруются в клиенте алгоритмом AES-256-GCM и хранятся зашифрованными, но ключи каналов создает, защищает и раздает сервер. Этот компромисс делает вход с нескольких устройств и восстановление простыми, но означает, что оператор сервера в принципе может читать сообщения. Если вы не доверяете тому, кто управляет вашим сервером, ведите деликатные разговоры в Whisper. Подробнее см. [Модель шифрования](../../security/encryption-model/).

## Из чего состоит Cove

| Компонент | Что делает |
|---|---|
| Сервер (`cove-server`) | REST API, WebSocket-хаб, WebRTC SFU, TURN, зашифрованное хранилище BadgerDB |
| Веб-клиент | Одностраничное приложение на React, раздается как статические файлы (образ Docker или любой веб-сервер) |
| Приложение для компьютера | Оболочка Wails вокруг веб-клиента для Windows, macOS и Linux |
| Приложение для Android | Нативный клиент на Kotlin |
