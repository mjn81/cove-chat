The API is JSON over HTTP. Errors are `{ "error": "message" }`. Web clients authenticate with an httpOnly session cookie plus an `X-CSRF-Token` header on mutations; the desktop app uses a Bearer token.

When the server runs with `server.dev = true`, an interactive Swagger UI is served at `/api/docs/`.
