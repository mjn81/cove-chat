## `[security]`

### `security.master_password`

Default: `""`

Master password for encrypting the database DEK via Argon2id (KEK derivation).
If left empty, the server will generate a secure 32-char random string on first
launch, print it to the terminal, and write it here automatically.
IMPORTANT: Back this up. Losing it makes the database unrecoverable.

## `[voice]`

### `voice.mode`

Default: `"webrtc"`

Group audio/video calling + screen share engine.
    "webrtc"  - production, internet-capable: a self-hosted SFU (see
    internal/rtc) with encrypted media (DTLS-SRTP) and NAT
    traversal via ICE/STUN/TURN. Supports video + screen share.
    "raw_udp" - the original unencrypted, audio-only UDP packet router
    (internal/voice), for isolated/LAN deployments where every
    client can already reach the server directly and the
    DTLS/ICE overhead isn't wanted. No video/screen-share.

### `voice.max_participants_per_call`

Default: `10`

Maximum participants in a single call (resource cap; enforced at join).

### `voice.webrtc_port_min`

Default: `50000`

WebRTC media (ICE/DTLS/SRTP) ephemeral UDP port range. Firewall this
range on the host; each active track negotiation uses one port.

### `voice.webrtc_port_max`

Default: `50100`

### `voice.public_ip`

Default: `"auto"`

Required whenever this process is behind NAT/a cloud load balancer/a
Docker port mapping — the IP clients should use to reach it. "webrtc" mode
is the internet-capable engine, so it's fine (and the default) for this to
assume internet access is available. Deployments with NO internet egress
at all should use mode = "raw_udp" above instead of "webrtc" with this
left empty.
    "auto"    - (default) auto-detect via a one-time STUN query at startup.
    Falls back to "" behavior if unreachable.
    ""        - direct/LAN-only "webrtc" deployments; never calls out.
    "1.2.3.4" - explicit manual value.

### `voice.public_ip_discovery_stun_servers`

Default: `["stun:stun.l.google.com:19302"]` (commented out in the example; optional)

Only used when public_ip = "auto"; overrides the default STUN servers.

### `voice.embedded_turn_enabled`

Default: `true`

Runs our own STUN+TURN relay in-process (github.com/pion/turn) so NAT
traversal works without any external TURN provider. Requires public_ip
to be set to be useful. Disable for LAN-only deployments that don't need
NAT traversal at all.

### `voice.embedded_turn_port`

Default: `3478`

### `voice.turn_realm`

Default: `"cove"`

### `voice.turn_shared_secret`

Default: `""`

Drives short-lived, per-call HMAC-derived TURN credentials (TURN REST API
convention) — never a static shared secret handed to clients directly.
Generated automatically on first run and persisted here, like
master_password above.
