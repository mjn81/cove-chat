● Features

Everything a community needs. Nothing it doesn't.

Shipped today, tested on web, desktop and Android.

🔐

Encrypted by default

Messages are AES-256-GCM encrypted in the client. Channel keys are wrapped by your master key; the database is encrypted at rest.

🤫

Whisper mode

Zero-persistence E2EE chats. Messages live in RAM and vanish when the session ends.

📞

Group calls & screen share

Built-in WebRTC SFU with DTLS-SRTP and embedded STUN/TURN. No third-party service.

⚡

One binary. One config.

Go server, BadgerDB, zero external dependencies. Runs on a Raspberry Pi or a cloud VM.

🛡

Admin & roles

Owner, admin, member. Invites, registration modes, audit log.

🌍

EN · FA · AR

Full RTL support and real translations.

📱

Every platform

Web, Windows / macOS / Linux, and native Android.

● How it works

You hold the server. You hold the keys.

The server routes ciphertext and manages keys, so multi-device and recovery just work.

💬 Your clientencrypts with AES-256-GCM
🖥 Your Cove serverroutes ciphertext · wraps keys · stores encrypted
👥 Membersdecrypt with channel key
Honest by design. Cove is server-trusted, not end-to-end encrypted: the server you control is inside the trust boundary. Need stronger guarantees for a conversation? Use Whisper.

● FAQ
Questions, answered.

  

    
Is Cove end-to-end encrypted?
Messages are encrypted client-side and stored encrypted, but the server you run manages channel keys. Whisper chats are true zero-persistence E2EE.

    
What do I need to run it?
Any machine that runs Docker or a Go binary. 1 CPU and 512 MB RAM is enough for small communities. ffmpeg is optional for video messages.

    
Does it work offline or on an isolated LAN?
Yes. Raw UDP voice mode is built for air-gapped networks.

    
Will servers be able to talk to each other?
Federation is on the long-term roadmap.
